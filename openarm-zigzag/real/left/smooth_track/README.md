## 实验 1: 轨迹时间轴/空间平滑 (2026-09-07) —— 结论: 已否决

| 方案 | 结果 |
|---|---|
| SG 空间平滑(窗 11) | ❌ TCP 切角 70mm, 走线几何不可接受 |
| SG 空间平滑(窗 5) | ❌ 仍切角 18.6mm |
| dt 滑动平均 | ❌ 构型翻转点(单步 J5 139°)速率尖峰 126°/s |
| 速度剖面平滑 | ❌ 相邻段主导关节交替, 标量平滑无效, 速率尖峰 440°/s |

**根本约束**: 路径位置必须一字不动(尖角几何), 可调的只有时间轴;
而每段的主导关节在交替变化, 标量时间/速度平滑无法消除逐关节台阶。
实测数据(成功走线段, 黑匣子): TCP 跟踪 mean=1.3mm, 抖动为 J1/J2
~2Hz、σ≈0.05 rad/s —— 主要来自**控制环路**(积分器/结构柔度)而非
轨迹几何。

**已采纳的对策**(主线, 2026-09-07): 积分器 ki J1/J2 24→12 + kd1 3.6 /
kd2 3.0 + 积分误差 EMA 平滑 —— 待真机复测对比 HF σ。

## 真正的 MPC 路线图(参考 CSDN 163364973, 第二/三阶段)

MoveIt2 无内置 MPC。三条路线(按落地成本排序):

1. **独立 MPC 节点 + MoveIt2 API**(快速原型): 速度型线性 MPC,
   OSQP 求解, 100Hz; 作为 JTC 之前的轨迹修正层。无需实时内核。
2. **ros2_control MPC 控制器插件**(工业推荐): C++ 插件替换 JTC,
   250Hz-1kHz, 需要 PREEMPT_RT 实时内核 + OSQP(线性)/Acados(NMPC);
   参考轨迹插值用 Ruckig。工作量: 天级~周级。
3. **改造 moveit_servo 内环**(视觉伺服场景): PID→笛卡尔 MPC。

共同数学框架: 速度型 QP(位置/速度/加速度三重限位 + 动力学传递)。
决策门槛: 若 ki/kd/EMA 调优后抖动仍不达标, 再启动路线 1;
路线 2 需先确认臂主板支持 PREEMPT_RT。
