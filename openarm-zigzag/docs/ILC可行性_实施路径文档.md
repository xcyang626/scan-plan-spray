## 1. 执行摘要

OpenArm 右臂在 x = 0.30 m 平面上执行重复性之字形扫描（`dense_zigzag_right.json`，811 个稠密点，5 mm 步长）。当前执行栈（JTC 主线：speed-scale 0.4 下 TCP 平均偏差 1.3 mm；MPC 执行轨：关节跟踪 ≤ 1.0°、指令高频 σ = 0.005）遗留一个特征明确的**系统性重复**误差分量——重力偏置残差、行末摩擦反向迟滞、沿固定路径的模型失配。这正是 ILC 所能消除的误差类别。

**可行性结论：可行，集成风险低。** 三个使能条件现有系统均已满足：

1. **重复性**——载荷是固定轨迹文件按固定重定时规则反复执行；参考指令的逐次变化按构造为零。
2. **日志**——100 Hz 黑匣子（`real/common/js_blackbox.py`，全关节位置/速度/力矩）已记录每次运行，无需新增任何测量即可获得逐次迭代误差信号。
3. **注入通道**——MPC 指令注入话题（新鲜指令覆盖 + 速率钳位 0.2 rad/条 + 绝对钳位 ±6.5 rad）是现成的、带防护的应用通道，无需改动电机固件或安全链。

**推荐架构：** 参考侧 ILC——学习逐关节、按时间索引的修正量 `u_k(t)`，叠加到轨迹参考上，经现有注入通道下发，迭代间离线计算。这是侵入性最低的 ILC 变体，**无需任何硬件或固件改动**（第 6 节）。

**预期效果（第 11 节，依据已发表的机器人 ILC 结果 [1]、[3]、[7]）：** 约 8–12 次受监督迭代后，RMS 关节跟踪误差降低 60–80%；TCP 平均偏差由 1.3 mm → ≤ 0.5 mm（speed-scale 0.4），并为 speed-scale 0.8 留出当前误差预算内的余量。以上为*预测值*；第 8 节定义了将其转化为实测承诺的测量流程。

**主要风险及其结构性对策：** 腕部翻转带（z ≈ 0.40–0.46 m 行区，J5 单步跳变最高约 160°）在*关节层面*违反 ILC 的逐次可重复性前提。本方案因此采用**分段学习 + 逐段准入闸门**（第 9.1 节），在源头（`make_dense_zigzag_right.py` 已实现的 `--zmin` 矩形收缩）排除该带之前，将其保持在 ILC 范围之外。

## 3. 技术背景：学习律与理论

### 3.1 问题定义

设试验序号 k，试验内离散时间序号 i（i = 0…N−1，N 为 10 ms 网格上的试验长度）。跟踪误差为

> e_k(i) = q_d(i) − q_k(i)，q_d = 稠密轨迹，q_k = 实测关节位置。

ILC 综合一个前馈修正量 u_k(i)（叠加到参考或力矩前馈上），由历史试验误差更新：

> u_{k+1}(i) = Q { u_k(i + m) + γ · e_k(i + m) }   （P 型 + 相位超前 m）

其中 γ 为学习增益，Q 为线性（典型为零相位低通）鲁棒化滤波器，m ≥ 0 为采样点数表示的时间超前 [1]、[4]、[5]。D 型与 PD 型变体用 e_k 的导数或 PD 组合替换 e_k；本项目推荐 **P 型 + 相位超前**：黑匣子直接提供位置，而微分 100 Hz 编码器数据会放大噪声（第 7.3 节）。

### 3.2 收敛性的两条标准论证路线

**压缩映射 / 频域路线（面向设计）。** 设 P(jω) 为*修正信号所看到的过程*的频率响应（对参考侧 ILC，即参考扰动到实测位置的闭环传递）。当 [1]、[4]：

> sup_ω | 1 − γ · Q(jω) · P(jω) | < 1

时，更新在 2 范数下单调收敛。此即压缩条件。其工程解读：γ·P 的轨迹必须落在以 1 为圆心的单位圆内；Q 的作用是剔除 P 增益/相位偏离 1 的频带，使剩余频带收缩。

**Lyapunov / 范数最优路线（面向分析）。** 在优化范式 [6] 中，更新 u_{k+1} 在线性模型 e_{k+1} ≈ (I − P·γ̂)e_k + 扰动约束下最小化 ‖e_{k+1}‖²_W + ‖u_{k+1} − u_k‖²_R；此时所选范数下的误差单调下降是定理而非整定结果。若固定 γ 整定被证明脆弱，范数最优 ILC 是本文档指定的回退方案（第 10.2 节）。

**两条路线的适用条件（任何后续评审中必须重申）：** 沿轨迹线性化后的线性时不变近似；逐次不变扰动 d（可学习）+ 有界逐次变化扰动 w_k（不可学习，须有界）；初始条件在容差内固定；各次试验采样网格与时间对齐固定。

### 3.3 本系统的学习对象

对参考侧 ILC，"过程"P 是**已由 PD + 重力积分器（+MPC，若启用）稳定好的闭环**。在远低于 PD 带宽的低频段，该环对参考扰动的跟踪增益 ≈ 1、相位滞后很小——对 P 型学习律近乎理想。这是本方案的核心集成洞察：**ILC 不与现有控制器对抗，而是给它一个更好的参考**（第 6 节）。

## 4. 本机械臂的收敛性分析（可直接使用的数据）

### 4.1 由已建成增益导出的闭环量

以 J2 列作为代表性刚性关节，取单关节等效惯量 J ≈ 1.0 kg·m²（9:1 减速关节的量级值；按第 7.6 节以辨识值替换——下方决策规则对 J ±50% 误差不敏感）：

- 自然频率：ω_n = √(kp/J) = √70 ≈ 8.4 rad/s ≈ **1.34 Hz**
- 阻尼：ζ = kd / (2√(kp·J)) = 3.0/(2·√70) ≈ **0.18**（欠阻尼，共振峰在 1.2 Hz 附近——与已记录的 J2 抖动一致，这正是 Q 滤波器截止频率必须低于它的原因）

本任务的误差频谱内容：重力偏置 ≈ 直流；行末摩擦反向突变集中在 ≈ 0.1–0.3 Hz。**全部可学习内容都位于 P ≈ 1 的频带内。**

### 4.2 按压缩条件选取学习增益

学习频带内取 Q = 1、P(jω) ≈ 1，条件 sup|1 − γP| < 1 给出 0 < γ < 2。对 P 增益不确定性 Δ（设 |P| ∈ [1−Δ, 1+Δ]）的鲁棒性要求 |1 − γ(1−Δ)| < 1 且 |1 − γ(1+Δ)| < 1，即 γ < 2/(1+Δ)。默认值：

| 模型误差容限 Δ | γ 上界 | **推荐 γ** |
|---|---|---|
| ±20 % | 1.67 | **0.6（生产默认）** |
| ±50 % | 1.33 | 0.6 仍安全：|1 − 0.6·0.5| = 0.70 < 1 |
| γ = 2.0 且 Δ = 10 % | — | |1 − 2·1.1| = 1.2 > 1 → **发散；用作发散检测基准，不是可用设置** |

γ = 0.6、P = 1 时的逐次残差：e_{k+1} = 0.4·e_k → 每次迭代误差降低 60%，约 6–10 次迭代到达噪声/可重复性地板。这与第 11 节的预测及文献范围 [1]、[3] 一致。

### 4.3 Q 滤波器与相位超前选取

- **Q：** 2 阶零相位 Butterworth（正向-反向滤波，无相位滞后），截止 **1.0 Hz**——低于 1.2 Hz 共振峰，高于 0.3 Hz 内容。零相位很关键：因果滤波器的相位滞后会侵蚀高 ω 处的压缩裕度 [4]。
- **相位超前 m = 1–2 个采样（10–20 ms）：** 学习频带内回路相位滞后的标准对策 [4]、[5]；P 在 1 Hz 内 ≈ 1 时 m = 1 即可。若早期迭代呈现缓慢振荡衰减（而非单调衰减），m 是第一调整旋钮。
- **遗忘因子 ρ = 0.98：** u_{k+1} = ρ·Q{u_k + γe_k}，以少量残差为代价，为逐次变化扰动下的学习幅值提供界——对抗非重复性漂移的标准保险 [1]。

### 4.4 扰动与模型不确定性下的稳定性保证

1. **可学习/不可学习扰动划分。** 只有逐次不变的部分（重力残差、随位置变化的摩擦、沿固定路径的模型失配）可被学习；逐次变化的部分（载荷变化、热漂移、伺服故障）表现为 w_k。反馈环仍是对 w_k 的主抑制机制；ρ < 1 的泄漏保证在有界 w_k 下学习信号有界 [1]。
2. **发散绊线（硬规则）。** 若 RMS(e_{k+1}) > 1.2 × RMS(e_k) 连续出现两次，或某关节 |u| 触及钳位且误差仍增长——中止学习并回滚 u。γ = 2.0 基准（4.2 节）即该绊线的标定用例。
3. **逐关节独立性。** 学习更新按关节独立进行；某 ESC 故障（参照已记录的 ESC4 锁存事件）仅禁用该关节的学习通道（第 13.3 节）。

## 5. 集成点评估与选定接口

对照现有栈评估了三个候选注入点：

| # | 注入点 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A | **参考修正**：u_k 叠加到 `q_ref`（JTC 或 MPC 之前） | 零固件改动；对两种执行器均有效；天然受现有速率/绝对钳位约束；回退极简（u = 0 即还原） | 学习内容限于闭环带宽（此处无关紧要——内容 ≤ 0.3 Hz） | **选定** |
| B | 经达妙 MIT 模式的力矩前馈 τ_ff | 物理上最快；绕过 PD 滞后 | 需驱动模式迁移（pos-vel → MIT）、看门狗交互再验证、逐关节力矩符号审计；影响面大 | 延后（Phase-4 选项） |
| C | MPC 参考变形（u_k 进 `mpc_core` 预测） | 与现有 MPC 协同；按构造满足 a_max | 与单一执行器耦合；整定面翻倍 | 待 MPC 成为唯一执行器后启用 |

**选定接口（A）一句话描述：** 离线学习器读取第 k 次试验的黑匣子日志，在固定 10 ms 网格上计算 u_{k+1}，写入轨迹文件旁；执行器在加载时把它叠加到 `q_ref`——运行时环不变。

### 5.1 数据流

```mermaid

    subgraph 运行时（第 k 次试验）
        A[dense_zigzag_right.json<br/>+ 学习补丁 u_k.json] --> B[执行器：JTC / MPC<br/>q_ref + u_k，10 ms]
        B --> C[伺服环<br/>PD + 积分器，CAN-FD]
        C --> D[机械臂]
        D --> E[js_blackbox.csv<br/>100 Hz q, qdot, tau]
    end
    subgraph 试验间（离线）
        E --> F{起点条件与<br/>新鲜度门通过？}
        F -- 否 --> G[丢弃该次试验：<br/>u_{k+1} = u_k]
        F -- 是 --> H[ILC 更新：<br/>网格对齐，e_k = qd - q_k，<br/>u_{k+1} = rho*Q{u_k + gamma*e_k 超前 m}]
        H --> I[发散绊线<br/>& 钳位审计]
        I -- 未通过 --> J[回滚 u，记日志，停止学习]
        I -- 通过 --> A
    end
```

### 5.2 迭代协议（每次试验的契约）

1. **前置条件：** 到达 home 位形；起点校验 ≤ 2°/关节（现有）；看门狗 OK；轨迹哈希 + speed-scale 与补丁文件匹配；u 钳位审计通过。
2. **试验：** 执行完整扫描；黑匣子必须记录全程（新鲜度/连续性检查：无 > 50 ms 断档）。
3. **后置条件：** 终点 FK 校验（现有）；记录试验结论。
4. **更新：** 按 4.4 节规则把门。任一门未通过 ⇒ 保持 u_k 不变（学习是幂等的；执行随时可以在不学习的状态下继续）。

## 6. 参数整定指南（默认值 + 决策规则）

| 参数 | 默认值 | 未按预期收敛时的决策规则 |
|---|---|---|
| 学习增益 γ | **0.6**（逐关节） | 2 次迭代后 RMS 应下降 ≥ 20%。若未达：先查网格对齐（7.1），再将 γ 减半。若 RMS 增长：触发 4.4 节绊线。 |
| Q 滤波器 | 2 阶零相位 Butterworth，fc = **1.0 Hz** | 误差衰减但过早平台化、行末有残差 → fc 升至 1.5 Hz。u 中出现噪声/高频增长 → fc 降至 0.5 Hz。 |
| 相位超前 m | **1 个采样**（10 ms） | 缓慢振荡衰减 → m = 2。持续增长 → m = 0 并复查 Q。 |
| 遗忘因子 ρ | **0.98** | 跨天可见逐次漂移（热漂移）→ ρ = 0.95。 |
| 初始条件 | 起点校验 ≤ 2°（现有），强制执行 | 违反 ⇒ 该试验无效、u 不变。绝不放宽以让 ILC "吸收" IC 误差。 |
| u 钳位 | ±[3, 3, 3, 2, 1, 1, 1] Nm（J1–J7），腕部保守 | 触钳位且误差仍增长 ⇒ 结构性问题（第 9 节），停止学习并排查。 |
| 参考安全裕量 | 学习后 q_ref 钳位到软限位 −1°（严于 3° 看门狗净空） | — |
| 停止准则 | 连续 2 次迭代 RMS 改善 < 5% | 冻结补丁；"冻结"指停止更新，不是停止使用。 |
| 迭代预算 | 12（预期 6–10 次收敛） | — |
| 试验有效性 | 黑匣子断档 ≤ 50 ms；起点校验通过；终点 FK 通过 | 任一失败 ⇒ 丢弃该次试验误差，保持 u。 |

**网格对齐（ILC 的经典陷阱，7.1）：** 各次试验必须以同一时间基准索引。重定时规则使 dt 成为轨迹的确定性函数，因此规范网格是 `dense_zigzag_right.json` 的*点序号 i* 经重定时公式的映射——绝不是对黑匣子做壁钟时间重采样。学习器用与执行器相同的插值把黑匣子日志重采样到规范网格上；实测 TCP 时序偏离名义值超过 10% 的运行无效，不参与学习。

**7.6 模型阶数说明：** 上面的 γ 与 fc 默认值由单关节二阶近似导出，J 已知到 ±50%。按 4.2 节，它们对该不确定性鲁棒。若获得完整辨识模型（按 [10]、[11] 的激励辨识），只需把 fc 提高到实测闭环带宽的 50–70%；γ 保持 0.6。

## 7. 分阶段实施路径

每阶段列出：目标、活动、进门/出门准则、回退方案。工作量以低/中/高表示，不用日历时间。

### Phase 0 —— 可重复性审计（仅离线；工作量：低）

- **目标：** 用现有数据量化逐次可重复性，以认证 ILC 前提。
- **活动：** 回放 ≥ 3 次同轨迹/同 scale 的存档 `js_blackbox.csv`；计算逐采样跨运行标准差与逐关节可重复性指标；依据跳变分析划定腕部翻转带边界。
- **出门准则：** (i) 可容许带内可重复性 std ≤ 0.5°/关节；(ii) 腕部翻转带正式排除出学习范围（或 Phase 2 采用逐段准入）。
- **回退：** 若可重复性 > 0.5°，收紧起点校验至 1° 并复审；ILC 仍有效但其地板（第 11 节）抬高。

### Phase 1 —— 学习器仿真验证（离线；工作量：中）

- **目标：** 在刻意失配的被控对象上验证更新律、网格对齐与绊线。
- **活动：** 使用已就位的 `openarm实验/ilc_sim/ilc_sim.py`（已消费真实轨迹文件）：对象 = 解耦双积分 + 库仑/粘滞摩擦 + 重力偏置 + 慢变负载扰动，参数与控制器假设失配 15–50%；运行实验矩阵 {γ = 0.6 + Q、无 Q、γ = 2.0 发散基准}；若工作区内有 MuJoCo 臂模型则加做验证。
- **出门准则：** 主实验 ≥ 8 次迭代 RMS 单调下降；无 Q 组呈现误差地板噪声增长；γ = 2.0 组触发绊线。（该工具的一次初步运行已复现预期定性表现；本方案交付的是修正轨迹段后的版本。）
- **回退：** 若 γ = 0.6 仿真中单调性失败，降为 γ = 0.3 + fc = 0.5 Hz；仍脆弱则切换为基函数 ILC（第 10.3 节）——其最小二乘更新在学习带内按构造无法发散。

### Phase 2 —— 真机影子模式（工作量：低）

- **目标：** 在不施加任何新动作的前提下验证*测量*通路。
- **活动：** 照常执行扫描；学习器从黑匣子计算 u_{k+1}；**不施加**；改为前向仿真预测误差下降，并与下一次自然运行的实测误差对比。
- **出门准则：** 预测与实测误差形状一致（可容许带内相关系数 ≥ 0.8）；学习 |u| 在钳位内；腕部带正确掩蔽。
- **回退：** 若不一致，说明学习器存在时间基准或符号错误——修复前不进行任何施加；机械臂从未暴露于风险。

### Phase 3 —— 受监督施加（工作量：中）

- **目标：** 先单行学习 3 次迭代，再全程，scale 0.4；然后 scale 0.8。
- **活动：** 在单行之字线上施加 u 共 3 次迭代（删除补丁即回滚）；扩展到完整可容许轨迹共至多 12 次迭代；以新的 (轨迹， scale) 补丁重复 scale 0.8。
- **出门准则：** RMS(e) 较 Phase-0 基线下降 ≥ 50%；无可归因于补丁的看门狗触发；全部钳位遵守；终点 FK 在现有容差内。
- **回退：** 任何异常 ⇒ 还原 u = 0（删除单个文件）；机械臂立即回到已认证的 JTC/MPC 行为。

### Phase 4 —— 生产化（工作量：低–中）

- **活动：** 以 (轨迹哈希， speed-scale) 为键的补丁库；带第 6 节停止准则的迭代管理器；逐关节学习使能/禁用（ESC 故障响应）；可选：把学习成果迁移为 τ_ff（注入点 B）或 MPC 参考变形（点 C）。
- **出门准则：** 无人值守迭代 + 自动回滚演练通过；交接链文档更新。

## 8. 关键挑战与推荐对策

### 8.1 腕部翻转带违反关节空间可重复性

实测 J5 单步跳变最高 160°，意味着相邻试验可能取不同腕部解支——ILC 学到的修正会在不相容构型间被平均。**对策：** 只在可容许带学习（z ≥ 0.46 m 行，或以 Phase-0 审计划定的边界为准），并把矩形收缩（`make_dense_zigzag_right.py` 的 `--zmin` / `--ymax-taper`）作为从源头移除该带的结构性修复。学习器内的逐段准入闸门使其自动化。

### 8.2 行末方向反转的摩擦迟滞

主导的*可学习*误差恰好出现在 ILC 最擅长处：确定性、与位置相关、每行重复。预期 Q/γ 默认值即可处理；若反转瞬态快于 0.3 Hz 内容的估计，按第 6 节提高 fc。

### 8.3 J2 高频抖动（1.2 Hz 附近共振）

已由加强 kd 缓解；ILC 绝不可在该频率之上学习。fc = 1.0 Hz 的零相位 Q 保证学习信号不进入该带；若 u 中出现抖动，可启用陷波变体（Q = Butterworth × 实测共振点陷波）。

### 8.4 起始条件敏感性

ILC 的经典失效模式是 IC 失配转化为学习到的误差瞬态。现有 ±2° 起点校验即闸门；保持严格，任何 IC 违规的运行一律记为无效试验（而不是误差数据）。

### 8.5 speed-scale 与轨迹变更

学习补丁仅对其 (轨迹哈希， scale) 对有效——重定时规则是已学习扰动的一部分。补丁按此为键存储；绝不在 scale 之间插值补丁。

### 8.6 伺服故障模式（ESC 锁存先例）

锁死的伺服会产生看似合理实则恒定的误差，学习器会去追。防护：每次更新前校验逐关节力矩-电流残差一致性（黑匣子已记录 tau）；指令-实测残差呈"恒定且大"特征的关节被标记，其学习通道禁用，该试验作废（第 13.3 节）。

## 9. 先进 ILC 算法（2020 年以后）及其对本项目的适用性

| 家族 | 核心思想（附锚点引用） | 本项目匹配度 | 实施路径 |
|---|---|---|---|
| **数据驱动 / 过去迭代信息 ILC（PF-IILC、DD-ILC）** | 从更新律中去除对象模型：增益乃至误差构成均由实测历史迭代数据构造；批过程方向的强主线 [12]，及动态线性化数据驱动框架 [13] | **良好，Phase-4 升级项**：我们的"批次"即一次扫描；当可重复性不完美时，用过去迭代的自适应 γ 替换固定增益 | 以 γ_k = ‖e_k‖/‖e_{k-1}‖ 比值调度替换固定 γ；Q 不变；同一工具链 |
| **无模型多变量 ILC（消除 L 与 Q）** | 直接从试验数据估计过程逆，MIMO 耦合，无需滤波器 [8] | **中等**：机械臂是 MIMO 耦合的；解耦关节假设是主要模型缺陷，该家族恰好吸收它 | 先从黑匣子数据估计过程频率响应（Phase-1 扩展）；若耦合误差以跨关节残差形态显现则采用 |
| **基函数 ILC** | 将 u 参数化到低维基（多项式/FFT/有理正交基），每次迭代解一个小最小二乘 [9]、[14] | **单位工作量的鲁棒性最佳；推荐回退与候选生产形态**：本任务误差形态光滑且低阶，≤ 20 项的 FFT/多项式基使发散在学习带内按构造几乎不可能，且补丁文件最小 | 在规范网格上逐次迭代做基系数 lstsq 拟合；集成通道完全相同 |
| **面向逐次变化/非重复任务的鲁棒 ILC** | 有界参考/扰动变化下的单调收敛；泄漏型设计在优化范式中被形式化 [6]，压缩族的鲁棒性分析见 [1]、[4] | **已内嵌**（ρ = 0.98 + 绊线）；当扫描速度变为逐次自适应时需要形式化 | 若 scale 调度动态化，改用范数最优更新 |
| **迭代学习 MPC（ILMPC）** | 学习前馈进入 MPC 预测；约束处理与学习稳定性纳入 MPC 框架 [15] | **天然的长期归宿**：`mpc_core.py` 已存在；学习 u 成为 MPC 的前馈/参考偏移 | Phase-4 选项 C：把 u 加入 MPC 参考；用现有离线验证器复核（基线跟踪 ≤ 1.0°） |
| **学习辅助整定（RL/BO 整定 ILC 参数）** | 从迭代日志数据驱动地整定 (γ, fc, 基维数) | **低优先级**：第 6 节的决策规则已编码整定逻辑；仅当多关节交互抵抗人工整定时重启 | 在仿真工具上做 (γ, fc) 贝叶斯优化 |

建议：先交付固定 γ 的 P 型律（第 4–7 节）；Phase 4 将**基函数 ILC**升级为生产形态（鲁棒性最好、补丁最小）；当逐次变化效应增大时启用 **PF-IILC**。

## 12. 硬件、实时性与故障处理注意事项

### 12.1 硬件：无需任何新增

- **算力：** 学习器在主机上离线运行（numpy/scipy；1000 点、7 关节的更新是毫秒级计算）。无边缘或固件改动。
- **传感：** 现有 100 Hz 编码器位置即足够（学习带 ≤ 1 Hz）。可选质量升级：经达妙寄存器读取关节力矩/电机电流用于 R4 残差校验——黑匣子已记录力矩。
- **通信：** CAN-FD 按 ISO 11898-1 [17] 1 Mbit/s 仲裁；指令规模不因参考侧 ILC 改变。

### 12.2 实时性

- **运行时环不变：** 10 ms 执行器，PD + 积分器 +（可选）MPC；ILC 只在参考加载时增加一次向量加法——每次试验 O(N) 一次，每周期零开销。
- **学习器时延：** 试验间进行；含全部验证门的完整更新在试验间停顿内轻松完成。迭代节奏受物理扫描限制，而非计算。

### 12.3 故障处理矩阵

| 故障 | 检测 | 自动响应 |
|---|---|---|
| 试验中途看门狗触发 | `/safety/status`（现有） | 试验无效；u 不变；正常 RETURNING 流程 |
| 黑匣子断档 > 50 ms | 学习器有效性门 | 试验无效 |
| RMS 发散 | 4.4 节绊线 | 回滚补丁，停止学习，告警 |
| 钳位饱和 + 增长 | 学习器审计 | 停止该关节学习 |
| ESC 锁存（ESC4 先例） | 指令-实测残差恒定且大 | 禁用该关节通道；试验作废；现有恢复流程不变 |
| 补丁/轨迹失配 | 加载时哈希校验 | 拒绝加载；执行器无补丁运行 |
| IC 违规 | 起点校验 ≤ 2°（现有） | 试验无效 |

**可逆性不变式：** 任意时刻删除 `u_k.json` 即精确还原已认证的 ILC 前行为。任何学习状态都不存在于驱动器或运行时环中。

## 13. 安全与标准对齐

- ILC 层只重塑**参考**；看门狗、急停、速率钳位（0.2 rad/条）、绝对钳位（±6.5 rad）与软限位净空保持在上游且独立——任何学习量都无法绕过它们。
- 学习后参考双重钳位：`real_safety.yaml` 软限位 −3° 看门狗净空之内，再减 1° ILC 裕量（第 6 节）。
- 机器人系统安全语境遵循工业机器人系统标准 ISO 10218-1/-2 [18]，未来任何接触/协作操作遵循 ISO/TS 15066 [19]；ILC 层不引入新的接触行为，不改变风险评估中对控制系统的假设（参考生成保持确定且有钳位）。
- 安全功能本身（看门狗、急停）的功能安全推理不变；按 IEC 61508 [20] 的分层模型，ILC 属于安全功能之外的普通应用软件（学习器不作 SIL 声明，也无需声明）。

## 附录 A —— 最小更新律（参考伪代码）

```text
输入 : qd[N][7]   规范稠密轨迹（经重定时映射到 10 ms 网格）
       q_log      第 k 次试验黑匣子位置，重采样到规范网格
       u_k[N][7]  当前补丁（首次试验为零）
       gamma=0.6, m=1, rho=0.98, fc=1.0 Hz, 钳位按第 6 节

e = qd - q_log                                   # 逐关节，规范网格
rms_new = rms(e, 仅可容许带)
if not valid(trial):      保持 u_k；退出
if rms_new > 1.2 * rms_prev（连续两次）:   回滚 u_k；停止学习；退出

for j in joints:                                  # 逐关节解耦
    e_lead        = shift(e[:, j], m)             # 时间超前
    u_new[:, j]   = rho * zerophase_lowpass(u_k[:, j] + gamma * e_lead, fc)
    u_new[:, j]  = clamp(u_new[:, j], -clamp_j, +clamp_j)
write u_{k+1} = u_new  （按 轨迹哈希+scale 键存储）
```
