# 舱室点云特征匹配：配准 + 语义标签传播（纯 numpy）

机器人自建的**黑白点云**（局部坐标系）与手持设备采集的**语义参考地图**（含
ground / wall / door / window / rib / other 六类标签）之间的三维刚体配准，
并把语义标签传播到机器人点云上——为后续工位规划、轨迹规划提供"机器人自己
认识环境"的点云地图。

核心是一个 **806 行的单文件实现**（`register_and_label.py`，文件头即完整算法
说明），从 k-d 树、法线估计到 ICP 全部手写，仅依赖 numpy + matplotlib，
不调用 PCL / Open3D。

## 方法

**为什么不走通用 FPFH + RANSAC？** 舱室是长方体，两侧点云对称性强，通用
特征描述子区分度差。本实现把领域先验用足（文件内同时保留了 FPFH + 几何
一致性 + RANSAC 的完整通用路径作对照）：

1. **粗配准——结构地标配准**
   - 墙角地标：墙面平面常数（各墙点坐标中位数）+ 地面高度 + 墙顶高度 →
     4 个墙角 × 上下端点共 8 个非共面地标，天然满约束 6 自由度；
   - 门框地标：门在墙上偏置，是不对称结构，用来消除墙角折叠 / 对称歧义。
     语义图直接取门标签包围盒；黑白图用墙面 (沿墙, 高度) 栅格连通域空洞
     检测门洞四角；
   - 三元组**距离几何一致性**匹配 + Kabsch(SVD) 求候选变换集，与
     "地面平面 + 质心"初始化一起，按**稠密点云最近邻重叠度**择优。
2. **精配准——自适应阈值点到面 ICP**
   每轮 ε_adp = μ_d + 0.1·σ_d 剔误配，点到面残差 + 李代数增量，
   残差 / 内点比例**双收敛判据**；源点云子集求位姿、收敛后回高密度。
3. **语义传播——体素哈希最近邻**
   配准回参考系后，3×3×3 邻域体素哈希查最近邻，迁移语义标签并写回 ply。

## 运行

```bash
# 依赖：numpy + matplotlib（任意 Python 3.8+ 环境）
python register_and_label.py
```

流程自动打印：两侧墙角 / 门框地标检测结果、粗配准 vs 真值误差、精配准残差
与 vs 真值误差、标签划分统计；输出 `舱室点云/舱室地图机器人扫描版本.ply`
与四视图 png。

**样例数据已附带**（`舱室点云/` 下两个 ply + 根目录 `gt_robot_scan.npy`
真值变换），开箱即可运行。原始全量点云约 500 万点、>100 MB 未入库；
从原始工程重新生成样例：

```bash
python make_sample_data.py --src /path/to/cabin_solution/点云.py
```

样例为 12 mm 体素降采样（语义图 30 万点 / 扫描 20 万点），配准指标与
全量数据基本一致；门框几何检测对稀疏化更敏感，个别情况下退回
"墙角 + 地面初始化"候选集，最终精度由自适应 ICP 收敛保证。
