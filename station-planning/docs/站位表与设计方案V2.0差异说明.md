# 站位表与《喷涂工位规划算法设计方案V2.0》差异说明

日期: 2026-10-09
范围: `station-planning/workspace/*.py`(站位单一数据源 `stations.py` 及全部校验脚本)

## 1. 背景

workspace 下 7 个脚本(fig_topview / check_candidates / check_cross / check_dr / check_zones / opt2 / solve_stiff)此前各自硬编码站位表, 与 `docs/喷涂工位规划算法设计方案V2.0.pdf` §2.3-2.4 的最终表格存在系统性不一致(审查项 B9), 且 7 份表中还互相不一致(L7 存在 3.595 与 3.53 两版混用)。

本次修复:

1. 新建 `workspace/stations.py` 作为站位表(左墙/右墙/前墙/后墙/墙角/作业顺序/覆盖带规则参数)的**单一数据源**, 7 个脚本全部改为从其 import, 删除各自的硬编码表;
2. 重写 `solve_stiff.py` 的 LP 约束, 使其编码 PDF §2.3-2.4 规则(修复 B5/B6);
3. 按校验闭环判定 stations.py 应取 PDF 值还是脚本值。

## 2. 校验闭环结果: 采纳**脚本版坐标**(情形 B)

### 2.1 LP 规则对齐验证(通过)

按 PDF §2.3-2.4 规则重写的 `solve_stiff.py`(约束: F1 角带 [0,0.40]、筋左定点=筋-0.40/筋右定点=筋+0.20、补齐站位=列左端+0.20、覆盖带 [u-0.20,u+0.60] 重叠衔接、无洞间距<=0.80、目标=与规则定点位置偏差最小), LP 解为:

| 站位 | LP 解 | PDF 表值 | 偏差 |
|------|-------|----------|------|
| F1   | 0.40  | 0.40 | 0 |
| L1   | 0.45  | 0.45 | 0 |
| L2   | 1.05  | 1.05 | 0 |
| L3   | 1.29  | 1.29 | 0 |
| L4   | 1.89  | 1.89 | 0 |
| L5   | 2.13  | 2.13 | 0 |
| L6   | 2.73  | 2.73 | 0 |
| L7   | 3.53  | 3.53 | 0 |
| L8   | 4.33  | 4.33 | 0 |

即"PDF 规则 => PDF 左墙表"对齐成立(容差 ±0.02 内逐项为 0)。

### 2.2 PDF 值代入几何校验(不通过 -> 不采纳 PDF 值)

将 PDF 表值与 PDF §2.4 作业顺序(墙面分组序 R2..R9 -> B5..B1 -> L9..L1 -> F1..F6)代入交叉检测, 存在 **3 处真实走位交叉**(非相邻线段严格相交):

- R8->R9 与 B4->B3 相交于 (2.43, 4.26)
- B2->B1 与 L8->L7 相交于 (0.80, 4.26)
- L2->L1 与 F2->F3 相交于 (0.80, 0.80)

注(坐标口径): 上述交点纵坐标按 workspace 几何(RY=5.058, 后墙走位线 y=RY-d_r=5.058-0.80≈4.26)计算; 若按纯 PDF 坐标(RY≈5.03, 即 §3.3 的 B5 y=4.23)则为 y=4.23。两种口径下 3 处交叉均存在, 结论一致。

根因: 墙端站位越过相邻墙的机器人走位线——右墙 R9(u=4.41) 与左墙 L8(u=4.33) 越过后墙走位线(y=RY-d_r=4.26), 左墙 L1(u=0.45) 越过前墙走位线(y=0.80)。墙面分组序下机器人沿墙线直行到底再转场, 必然横穿邻墙走位线。PDF §2.4 "动线无交叉" 的声明与其自身坐标在几何检测下不符。

按预定判定规则(任一 check 不通过即不改 PDF 值), **stations.py 保留脚本版坐标**(经 check_zones/check_cross 全部判据通过的那套; L7 统一取 3.53, 因 3.53 同时是 PDF 值且已通过校验), 墙角(对角内收型)与作业顺序(局部交换序)维持脚本版。

脚本版(局部交换序)校验输出摘要: check_cross 交叉数 0、开放走位 14.11 m; check_zones 覆盖带相接无重叠、整墙全覆盖、各墙间距<=0.80; opt2 对原始墙面分组序 2-opt 后交叉 0、长度 13.37 m（该 2-opt 序与 ORDER 是两种不同的无交叉序, 并非等价, 差异与取舍见 §3.4）。

### 3.3 墙角站位

- 脚本: 对角内收型 C_FL/C_FR/C_BL/C_BR = (0.40,0.40)/(2.83,0.40)/(0.40,4.66)/(2.83,4.66), 45°面向墙角, 每角一个独立命名站位;
- PDF: 角站设在**所在墙上距墙端 0.40m** 处并列入该墙站位表(F1(0.40,0.80)、F6(2.83,0.80)、B5(2.83,4.23)、L9(0.80,4.66)), 每墙角融合删除对侧冗余角站(旧R1/R10/B1/L1)。

### 3.4 作业顺序(角点次序)

- 脚本(局部交换序): ...R9 -> **B4 -> C_BR -> B3** -> B2 -> **C_BL -> B1** -> L8...L1 -> **F2 -> C_FL -> F3** -> F4...; 墙角站位插入墙面中间以消除交叉;
- PDF(墙面分组序): ...R9 -> **B5 -> B4** -> B3 -> B2 -> **B1 -> L9** -> L8...L1 -> **F1 -> F2** -> F3...; 角站位于各墙首/末。
- 两处在 B1/后左角与 F1/F2 处的角点次序相反; PDF 序存在 3 处走位交叉(见 §2.2), 脚本序交叉为 0。
- 与 2-opt 序的关系: opt2 对原始墙面分组序做 2-opt 得到的无交叉序(13.37 m)与 ORDER(局部交换序, 14.11 m)**不等价**——2-opt 序把 R9、L1 移出所在墙的分组(如 R2..R8→B4→C_BR→**R9**→B3..、L8..L2→F2→C_FL→**L1**→F3..), 而 ORDER 各墙站位仍按墙分组连续推进, 仅把墙角站位插入墙面中间。
- 未采纳 2-opt 序的原因(推断, 仓库内无明文记录): ORDER 保持了与原始墙面分组序更接近的工位推进逻辑(逐墙连续作业, 墙角就近插入), 2-opt 序虽短 0.74 m 但改动角点次序较大(R9/L1 跨墙穿插), 与"按墙分组推进"的作业组织方式偏离。

### 3.5 覆盖带规则

- 脚本: 相邻覆盖带**互不重叠、相接**(边界=两站位中点, 截断至可达范围交集 [u-0.2, u+0.6]);
- PDF: 相邻覆盖带**重叠衔接**(每带=[u-0.20, u+0.60], 相邻带重叠, 如 L1 带[0.25,1.05]与L2带[0.85,1.65]重叠 0.20m), 角带[0,0.40]与 L1 带重叠衔接。

### 3.6 其他

- L7: 脚本内部原两版混用(check_candidates/check_dr/opt2/solve_stiff 为 3.595, check_cross/check_zones/fig_topview 为 3.53), 本次统一为 **3.53**(PDF 值, 且通过全部校验);
- 后墙筋位置: PDF 表 B3/B4=2.05/2.65 反推筋中心 u≈2.45, 而前墙 F4/F5=2.01/2.61 反推 u=2.41, 脚本 stiff_pos 前后墙均取 2.41; 前后墙筋位是否确有 4cm 差, 需以点云复核。

## 4. LP 规则冲突原因(B5/B6, 已修复)

旧 `solve_stiff.py`:

- 对 ("F1","L1") 施加 **L1 >= F1 + 0.4** 最小间距约束。PDF 方案中 F1 角带 [0,0.40] 与 L1 带 [0.25,1.05] 重叠衔接(L1=0.45 < 0.40+0.4=0.80), 该约束使 PDF 方案在 LP 中**不可行**; 旧 LP 在 F1=0.20 时解出 L1=0.60、L3=1.45、L5=2.29, 正是脚本版坐标的来源(两套规则并存的机制性原因)。
- `add(-P("L1"), 0.25)` 实为 L1 >= -0.25(无效下界), 审查疑为 0.35 之误。验证: 无论下界取 0.25 还是 0.35, 在 F1-L1>=0.4 约束下 L1 均被推至 0.60, 单改下界不能产生 PDF 解 L1=0.45; 只有按 PDF 带宽规则编码(L1 带 [0.25,1.05], 即 L1=0.45)才行。新 LP 已以筋定点等式(L1=筋1-0.40=0.45)取代该下界。
- 旧 41-44 行存在成对重复约束(如 `P("L2")-P("L3") <= 0` 写两遍), 以及各相邻站位对统一的 >=0.4 间距约束(与 PDF 重叠衔接规则冲突), 均已删除。

新 LP 见 `workspace/solve_stiff.py`(编码 PDF §2.3-2.4 规则, 解出的即 §2.1 表格值, 作为"规则=>表格"的对齐验证工具保留)。

## 5. 结论

1. stations.py 现行为**脚本版**(已通过全部几何/覆盖校验): 左墙 0.60/1.05/1.45/1.89/2.29/2.73/3.53/4.15, 右墙 1.29/1.89/2.29/2.73/3.13/3.57/3.97/4.41, 墙角对角内收, 局部交换序, 覆盖带中点截断相接;
2. PDF V2.0 表值本身规则自洽(LP 复现), 但其作业顺序在交叉检测下不成立(3 处交叉), 且其墙角模型/筋左偏移(0.40)与脚本可达区校验链(0.24)结论不同;
3. **需设计侧重新审定**(建议: 确认筋左定点偏移取 0.40 还是 0.24 及其可达性依据; 确认墙角站位模型; 给出无交叉的作业顺序或修订坐标使墙面分组序无交叉, 例如约束墙端站位不越过邻墙走位线), 审定后刷新 stations.py 并重跑 check_zones/check_cross/check_candidates/check_dr/opt2 全套校验。
