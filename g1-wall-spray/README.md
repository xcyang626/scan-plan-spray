# G1 舱室墙面喷涂（点云 → 轨迹 → 工作站 → 实机）

从舱室语义点云中提取墙面喷涂区段，为宇树 G1（腰 3 + 臂 7×2 + 腿 6×2）规划
**站+蹲双姿态**水平行走线喷涂轨迹，经网页工作站一键生成动作并下发——同一套
代码支持 MuJoCo 仿真与物理 G1 实机（`robot_mode` 一项切换）。

> **当前状态（V3 定稿 + 实机验证，2026-10-12）**：真实 G1 已完成全带喷涂
> （站姿 0.75–1.45m 8 行 → 五段过渡缓慢下蹲 → 蹲姿 0.35–0.65m 4 行 → 起身，
> ×1.0 全程 155.6s / 0.5× 可选）。站立段零模式翻转不晃，下蹲过程柔顺
> （最大降速 0.13 m/s）。能力演进编年史见 **[README_版本迭代.md](README_版本迭代.md)**，
> sim/real 后端差异与安全操作见 **[README_仿真版与实机版区别.md](README_仿真版与实机版区别.md)**。

## 快速开始

```bash
# 0) 本机配置: 复制通用配置为本机覆盖层(不入库, 加载时整体覆盖同名字段)
cp station/env.json station/env.local.json   # 填 isaac_py/mujoco_py/groot_* 与 robot_mode

# 1) 启动工作站(解释器可用 MUJOCO_PY 指定)
./启动工作站.sh                               # http://127.0.0.1:8090

# 2) 网页流程(实机与仿真完全一致)
#    ① 启动机器人 → (首次建议先点急停测试) → ② 生成轨迹 → ③ 检查 → 生成动作
#    → ④ 执行(可选 0.5× 倍速)
```

- **仿真模式** `robot_mode: sim`：MuJoCo + GR00T 策略，无需机器人。
- **实机模式** `robot_mode: real`：需网线直连 G1 调试口（详见区别 README 第四节与
  网线诊断一节）；启动后自动完成 启动控制 + planner 模式 + 保持流，无需手动按键。
- 实机值守：**手柄 F2 / 网页红色急停 / `estop.py`** 三层软急停（全身变软阻尼态），
  详见区别 README 第六节。

## V3 定稿走线规范（当前口径）

- **水平横向走线**：每行腕心走水平直线（行内 z 标准差 ≈0），行方向交替；
  枪臂恒在"机器人-墙面法向"垂面内（**横向分量 = 0，纯俯仰指向**）；
  行角按高度阶梯取 **60/70/80/90°**（低行下倾、高行上倾、中段垂直）。
- **双姿态分带**（蹲姿地板 0.35，两带同 u 区间对齐）：站姿带 8 行 0.75–1.45m
  （骨盆恒 约 0.754m）+ 蹲姿带 4 行 0.35–0.65m（逐点骨盆参考 0.35–0.56m）。
- **腰部**：yaw 硬限 **±45°**（防 IK 冗余拧腰拖转底座），roll/pitch 限 ±5°。
- **站→蹲过渡（V2.2 五段时序）**：收臂（按关节行程自适应，峰值限 约 2.2 rad/s）
  → 零位停顿 1.2s → **纯下蹲 5.9s**（臂贴身零位，0.07 m/s 慢降）→ 蹲底停顿
  1.5s（等策略收敛）→ 蹲姿下伸出；结尾回位同律自适应（约 6s）。
- 底部 0–0.35m 延伸带（弯腰档）代码保留但默认关闭，后续开启。
- 质量审计（03/05 自动执行）：IK 全点严格收敛、枪-墙夹角 ≥60°（实测 61.6–90°）、
  指向 dot ≥0.965、臂-腿自碰撞 0、帧速峰 ≤ 约 2.7 rad/s。

## 实机执行链路（robot_mode=real）

```
网页/HTTP API ── ZMQ 5558 ──> groot_daemon(常驻) ── ZMQ 5556 planner 话题 ──> C++ SONIC 部署 ── DDS ──> 物理 G1
                                  │ 5557 g1_debug 反馈(q29)
                                  └ 保持流 50Hz / 上肢 17 关节@50Hz(SONIC 交错序, 梯度速度, 结束保持末姿)
```

- **蹲姿通道（V2.1h 分段门控）**：高度/模式/骨盆外环只在蹲姿段（参考 z<0.70）
  发送——站姿段 `height=-1, mode=None`，与纯站姿动作同通道；模式滞回挂参考高度
  （<0.66 进蹲 / ≥0.70 回站）。> 背景：首跑曾因"高度通道全程开 + 外环负纠偏 +
  模式滞回"锁成极限环，机器人上下摇晃（详见版本迭代 10-12 节）。
- **骨盆外环**：5557 实测 q29 腿部平面几何反解骨盆高，K=1.8、纠偏 ±0.10、
  指令限幅 [0.28, 0.85]（带臂负载蹲不深时自动加深指令）；仅蹲姿段闭环。
- **任务空间慢环（V2.1g）**：腕心世界位姿残差 10Hz 积分修正上肢 17（腰 yaw 禁用）。
- **执行统计**自动进页面日志：骨盆最低 / |骨盆-参考|max / 上肢跟踪 err /
  腕心高度偏差（走线水平度）/ 枪偏离法向。
- 部署二进制与 SONIC 资产在 GR00T 克隆 `gear_sonic_deploy/`（需先构建）。

## 安全设计小结

- 站点默认 **仅绑 127.0.0.1**（接口无鉴权，不要用 `--host 0.0.0.0` 暴露公网）；
  上传限 200MB + 点云类型嗅探；静态文件/动作下发均为路径白名单（防目录穿越）。
- 实机执行安全：速度倍率限幅、NaN/inf 归一、取消走官方保持序列、两级软急停
  （变软非刚性归零）+ 进程退出确认；蹲姿动作必须配蹲姿通道启动（否则拒绝执行）。
- 公开仓库脱敏：本机路径/内网配置只放 `env.local.json`（.gitignore）；
  registry 路径支持 `~`；子进程全部列表参数无 `shell=True`；`np.load` 的
  pickle 仅用于本地自产 npz。

## 已知限制与下一步

1. **蹲姿行落点偏低 10–15cm**（腕心偏差 约 15cm / 枪角偏大）：蹲姿下伺服缺骨盆
   俯仰反馈，待补骨盆俯仰估计或弯腰档重规划；当前先靠分段过渡保稳定。
2. 0–0.35m 贴地带需弯腰档（代码保留，默认关）或行走喷涂扩宽（SONIC planner
   消息原生带 `movement`/`facing` 位移指令字段，横走喷涂待验证模式耦合与
   底座反馈）。
3. 真机无底座位姿反馈（odom/IMU 二期），底座快环未移植；基座补偿目前为验证
   脚本 + 慢环部分能力。
4. 首次实机建议流程：sim 验证轨迹 → 实机启动 → 急停测试 → 0.5× 空跑 → 全速。
