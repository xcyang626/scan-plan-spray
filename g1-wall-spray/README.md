# 宇树 G1 舱室墙面喷涂轨迹规划（基于点云地图）

真正的"用点云信息做轨迹规划"演示：从舱室语义点云地图中提取一面墙的喷涂区段，
用宇树 G1（29DOF，官方 URDF `g1_29dof_nohand.urdf`）的运动学计算工作区域，
生成站姿单一模式的等宽完整之字形喷涂轨迹（墙面轨迹 + 机器人轨迹）：腰
roll/pitch 限幅 ±5°（保稳定，更保守裕度），统一 u 区间 [0.115, 0.605]
（宽 0.49m），行高 0.55→1.45m，共 307 点，并对机器人轨迹逐点做逆运动学（IK）
可达性验证（307/307 全部通过）。

## 步骤2：G1 工作区域（`02_g1_workspace.py`，与方案文件方法一致）

- 关节链：腰(yaw/roll/pitch) + 右臂7关节；**"末端的前一个关节" = 腕 yaw 关节中心**，
  喷枪轴 = 腕 yaw 系 x 轴（前臂延长线）
- **定位误差处理**：机器人离墙 d∈[0.70, 0.78]m ⇒ 腕平面在基座系 x_w = d−0.40 ∈
  [0.30, 0.38]m（标称 0.74m）。对 x_w = 0.30/0.34/0.38 三个平面分别建立"腕心 (y,z) 占据网格"，
  **取交集 = 定位误差全程保证的垂直工作区域**
- 垂直判据：喷枪轴与墙面法向夹角 ≤15°；倾斜判据 ≤30°（即与墙面夹角 ≥60°，
  喷涂质量约束；用于底/顶/侧边缘的指向位姿）
- 骨盆高度：站姿 0.77~0.79m；蹲姿 0.60~0.70m（**策略友好下限 0.60**，
  避免深蹲分布外姿态；腿部 FK 足底贴地可行域 P2≈0.42m）；腰扭 ±60°（±30° 也已计算，宽度不够）

**结果（右臂、腰±60°、三平面保证区）：**

| 模式 | 垂直可达 y 范围 | 段带内垂直 z 范围 | 实心 z 范围 |
|------|----------------|------------------|-------------|
| 站姿 | [−0.46, +0.30] m | [0.69, 1.38] m | [0.88, 1.18] m |
| 蹲姿 | [−0.46, +0.30] m | [0.55, 1.26] m | [0.75, 1.06] m |

站/蹲垂直带重叠 [0.69, 1.26] ⇒ **高度分界 z_split = 0.90m**（用户原始分界，在重叠区内；
v4 起改为站姿单一模式，不再蹲/站分区，此分界仅作蹲姿工作区参考）。

## 步骤3：之字形轨迹（`03_plan_trajectories.py`）

### 设计（用户定稿）：站姿单一 + 等宽完整之字形 + 腕心水平线 + 行角离散 {90,80,70,60}°

1. **站姿单一模式**：只保留站姿（骨盆 0.77~0.79m），无蹲/站分区、无回零位停顿；
   腰三自由度放开但限幅——roll/pitch 限 **±5°**（±0.0873 rad，保稳定，
   远离 ±30° 物理限位），工作区按腰 yaw ±60° 计算（与步骤2一致）
2. **等宽完整之字形 + 腕心水平线（核心）**：每一横的墙面 u 区间完全相同 ⇒
   **统一 u 区间 [0.115, 0.605]（宽 0.49m）**，行方向交替、行端竖直 U 型换行；
   **腕心走线为干净之字形**——行内水平直线（每行腕心高 z_w 恒定，自检行内 z
   标准差≈0）、与墙面行同宽同步扫描（腕心横向 = 墙面 u − 0.44m）、指向纯俯仰
   （横向分量恒为 0）
3. **行高 0.55→1.45m + 行角离散 {90, 80, 70, 60}°**：共 10 条横向走线
   （行距 0.10m：0.55/0.65/…/1.45m；0.55m 以下站姿不可达，见已知限制）。
   行角 θ 为行常数（取最大可行档），腕心高 z_w = h + dir·0.40·tan(90°−θ)
   （dir=+1 枪下倾 / dir=−1 枪上倾，θ=90° 垂直）：

   | 行高 h (m) | 腕心高 z_w (m) | 行角 θ | 指向 |
   |---|---|---|---|
   | 0.55 | 0.781 | 60° | d+（下倾） |
   | 0.65 | 0.796 | 70° | d+ |
   | 0.75 | 0.821 | 80° | d+ |
   | 0.85 | 0.850 | 90° | 垂直 |
   | 0.95 | 0.950 | 90° | 垂直 |
   | 1.05 | 1.050 | 90° | 垂直 |
   | 1.15 | 1.150 | 90° | 垂直 |
   | 1.25 | 1.250 | 90° | 垂直 |
   | 1.35 | 1.280 | 80° | d−（上倾） |
   | 1.45 | 1.219 | 60° | d− |

   （行角分布：90°×5、80°×2、70°×1、60°×2）
4. **喷涂质量**：连接段指向在两行角之间线性插值（仍纯俯仰，≤30°）。**终检**：
   对最终关节解 FK 实测枪轴，与墙面夹角全程 **[60.0°, 90.0°]**（全部 ≥60°）

### 墙面轨迹与机器人轨迹

- 走线统一单色，单条连续之字形贯穿 0.55~1.45m，区内全程顺滑不回位
- 共 **307 点**（喷涂走线段 260 + 竖直连接段 47，统一红色一类，无停留点），
  统一 0.05 m/s
- 机器人轨迹：腕心距墙 0.40m（站位标称 0.74m，0.70~0.78 全程保证）、横向
  u=0.44m；**最低点 z=0.781m ≥ 0.15m**（要求值）
- **逐点 IK 验证**：批量阻尼最小二乘（解析雅可比，变量=腰3+臂7+骨盆高），
  MC 最近邻 4 种子 + 邻点热启动波次，**307/307 收敛**（严格档 307、边缘档 0、失败 0）

导出流程（v5_stand_zigzag，数字取自 `output/ufo_motion/v5_stand_zigzag/motion_meta.json`）：

1. **腰三自由度全程解锁**：自由变量 q10 = [腰yaw, 腰roll, 腰pitch, 右臂7] 共 10 维
   直通 qpos（腰=19:22、右臂=29:36），与步骤3 URDF 规划一致（roll/pitch 限幅 ±5°），
   不再有 v2/v3 的腰锁定 8 维映射；
2. **骨盆高度站姿单区恒定 0.77m**（实测 0.754~0.758m，init 0.7742m）——无蹲/站分区与
   回零位停顿，避免 IK 逐点自由骨盆抖动；
3. **在 MJCF（g1-mode_13_15.xml）内重解 IK**：MJCF 与官方 URDF 存在 mm 级连杆原点差异，
   以 URDF 解为种子严格顺序热启动（不换构型分支）；**307/307 收敛**
   （位置<4mm、轴<0.05，容差档 ≤10mm 0 点，边缘微松 0 点，跳变 0）；
4. **时间轴**：实际腕心路径按弧长积分，统一 0.05 m/s，行端停留 0.25s；
   全程 5.33m、116.23s（3487 帧），腕心离地高 0.779~1.22m；
5. **相位**：保持 1.5s → 2.5s 过渡 → 跟踪 109.19s → 2.0s 回位 → 保持 1.0s；
   **腿**：骨盆高度平面站姿 IK（足底贴地）；**左臂**：init 站姿常数（g1.json init_state）；
6. 节点级连续性整流 + **轻度平滑（3帧）** + 逐帧贴地校正（全关节最大速度 **2.21 rad/s**，
   回位块以最终跟踪末帧重锚定，消除修复后接缝阶跃）；
7. **枪轴修复 + 审计（喷涂质量）**：修复块边界 smoothstep 混合，**最后逐帧 FK 实测

   dot 0.9992~1.0）；连接段（yellow）帧 264，全部在 25mm 内（最大 16mm）——
   连接段不喷涂、免角度规范，仅报告不设硬阈值。

**加速（智能方法）**：05 以 03 输出的连续 URDF 解作增量种子（iters=60 早停），

03 亦改为锚点(78)+CubicSpline+增量修正的快速 IK，**0.9s**（旧版约 120s）。

## 步骤6：MuJoCo 仿真验证（`06_replay_render.py` + MimicLite sim2sim）

1. **动作回放（运动学）**：`replay_motion.mp4` / `fig_replay_contactsheet.png` ——
   参考动作在官方 g1-mode_13_15.xml 中逐帧回放，蹲起/之字/回位全部正确、足底贴地。
2. **MimicLite ppo 策略跟踪（动力学）**：`auto_track.py`（键盘注入在无终端环境失效,
   sshkeyboard 需要真实 tty，故用包装器自动切换 zero→policy→unpause，等价于 i/]/空格键）。
   仿真结论：
   - **弹性带(Elastic Band)开着会把机器人拽飞**（walk1 已知动作同样飞天）——这是之前
     之字形实验失败的直接原因之一；跟踪前必须在 viewer 里取消勾选 Enabled；
   - 禁用弹性带 + 干净复位后：机器人全程站立不摔，**手臂能部分跟随喷涂动作**，
     但策略（LAFAN 舞蹈/行走数据训练）对"原地深蹲+贴墙喷涂"这种分布外动作
     不执行深蹲、跟踪质量不足；
   - 参考数据本身已验证无误：any4hdmi 缓存中的参考与我们 npz 相关系数 1.000。
   后续改进方向：用含蹲姿/工业动作的数据微调策略，或降低蹲深/改为蹲姿专用检查点。
3. **喷涂顺序（用户定稿）**：站姿喷上半区（从分区线 0.95m 向上到 1.45m）→ 回零位
   （动作中插入 2.6s 站立停顿）→ 蹲下喷下半区（从分区线 0.85m 向下到底 0.05m），
   全高 0~1.5m 无遗漏；`auto_track.py` 支持自动 zero→policy→unpause 切换
   （键盘 sshkeyboard 在无终端环境失效，已绕过）。
4. **交互式运行的正确姿势**：viewer 中 Reset（机器人趴姿为 MJCF 初始态）→ 勾选
   Elastic Band 把机器人拉起站住 → 启动 auto_track（policy-paused 对齐站立帧）→
   **手动取消勾选弹力带的时机需要人扶一下**（策略无接管平衡能力，远程自动化止步于此）
   → 空格/自动解除暂停开始跟踪。

## 一体化工作站与 ROS 输出（`scripts/10-12`）

**机器人执行（GR00T-WBC）**：网页流程升级为「① 启动机器人 → ② 生成轨迹 → ③ 动作并打包 → ④ 自动执行」。
① 拉起 GR00T-WBC 仿真+策略（RL 下肢平衡），机器人回到初始站姿待命；④ 把本轮动作（腰3+右臂7，
带速度前馈）注入策略的 PD 目标，机器人按墙面轨迹喷涂，播完自动回待命（可重复执行）。

一致(nq=36)、复现喷枪位姿 ≤4mm/≤1°；右臂跟踪 max 0.65°，骨盆 0.74~0.75m 稳定。配置见 station/env.json。

## 已知限制（"先弄一个出来看看"）

1. **蹲姿下半区暂未规划（后续再加）**：当前 v5_stand_zigzag 只喷站姿带 0.55~1.45m；
   蹲姿工作区已算好（步骤2），下半区之字形轨迹与蹲姿动作导出待后续版本加入。
2. **墙面 0~0.55m 站姿不可达**：等宽之字形的统一 u 区间以最低行 0.55m 为界，
   0.55m 以下需蹲姿覆盖（见上条）。
3. **连接段过渡（非喷涂段，v5 已收敛）**：换行连接段不喷涂、免角度规范；
   v5 最终版经 03 连续解增量播种后 MJCF-IK **跳变 0 处**，连接段 264 帧
   腕心位置偏差全部 ≤25mm（实测最大 16mm，dot≥0.999），无速度尖峰
   （全关节最大速度 2.21 rad/s）。
4. 红色穿越段直接从窗户开口/管道前方快速通过（按要求），实际部署需确认喷枪
   与 125mm 加强筋、凸出管道的净距（腕心距墙 0.40m，枪长 0.12m ⇒ 喷嘴距墙约 0.28m，
   大于加强筋凸出 0.125m 与管道凸出 ~0.17m，但穿越管道正上方时喷嘴高度会逼近管顶）。
5. 行距 0.10m 对应喷涂半径 ≥0.05m（锥半角 ≥9°@0.28~0.40m 站距），可按喷嘴实际
   锥角在 `PITCH` 调整。
6. 蹲姿骨盆 0.60~0.70m 的稳定步态/平衡未建模（演示为静态站位）。
