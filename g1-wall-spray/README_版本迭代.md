## 2026-10-12 —— V3 定稿 + 实机首跑（关键一天）

  机器人-墙面法向垂面内（横向分量=0），行角 60/70/80/90° 沿高度阶梯。

  全绿验收（帧速 2.3、角度 61.6–90°、碰撞 0、仿真不摔）。
