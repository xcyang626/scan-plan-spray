# V2 移动喷涂推进计划（双姿态 → 对墙 → 行走扩宽）

> 2026-10-10 建立。V2 原则：**不覆盖 v5 站姿链路**——所有改动挂在 `posture=dual` /
> `G1W_OUT=output/v2_dual` 开关下，默认行为与 v5 完全一致（已回归确认）；
> 每一步都先在仿真里过关（数值门槛 + MuJoCo 回放/策略仿真）再考虑实机。

## 总目标（老板指标）

1. **高度 0–1.5m**：站立+蹲下双姿态覆盖（V2.1，本次完成大部分）
2. **自动对墙**：启动时站位可能不正对墙面，机器人自动转向（V2.2）
3. **宽度 0.8m**：单站可达不够（±5° 腰限下站姿带仅 0.19m 宽），靠行走扩宽（V2.3）

### 已知边界（如实）

1. **0–0.20m 贴地带仍未覆盖**（当前覆盖 0.20–1.50m）。几何硬约束：枪-墙夹角 ≥60°
   （倾角 ≤30°）+ 腕平面 x 0.30–0.38（站位 0.74m）下，可喷下限 ≈ 蹲姿骨盆地板 − 0.22m；
   策略地板实测 0.29m（理论上能到 ~0.07），但带臂负载与动态裕量下取 0.40。
   往下走的三个选项（需用户决策）：
   - **弯腰**：放开腰 pitch（现 ±5° 用户定稿）到 ~25–35°，叠加深蹲可到 ~0.10m——
     需重做 02/03（腰 pitch 进网格）、验证策略 rpy_cmd 通道与自碰撞；
   - **更近站位**：下半段专用站位 d_robot ~0.55–0.60（腕平面 x ~0.15–0.20），需新工作区
     网格与站位切换执行（V2.3 行走扩宽时可顺带）；
   - **蹲到策略极限**（骨盆 ~0.30）：OOD 风险高（带臂未验证），仅实验。
2. **带宽受腰 roll/pitch 档位限制**：±5°→站/蹲统一 0.19m；README 记录 ±20°→0.51m。
   V2.3 行走扩宽是主出路。
3. 回零位过渡 ~5s（收臂 1.0s + 停顿 1.2s + 限速下蹲 ~2.8s）喷枪离开墙面；
   下蹲限速 0.12m/s 是策略跟踪能力决定的，连续下蹲版本需策略侧支持。

## V2.1b 策略层仿真过关 —— 已完成（2026-10-10）

**结论：蹲姿执行通道打通并实测通过。** 关键发现：一直在用的平衡控制器
（`run_mujoco_gear_wbc.py`）的观测里本来就有 `command[3] = control_dict["height_cmd"]`
（官方键盘 1/2 就是实时调高度），**不需要换 gait 控制器**——runner 播放期把动作的
骨盆高度轨迹写进 `height_cmd`，平衡策略自己下蹲。

- 实现：`exec/groot_spray_runner.py` 新增 `--height`（主通道）与 `--legs motion`
  （运动学腿跟踪，实测起播跳变会摔，仅作备选）、`--gait`（gait 变体实验入口）；
  播放期摔倒检测（骨盆<0.35m 停机）+ 蹲姿执行摘要（骨盆最低/跟踪误差/是否摔倒）。
- 无头实测（v7_dual_deep 深蹲版全程）：**完整播放不摔**，骨盆最低 **0.391m**；分段骨盆
  跟踪误差：站姿段 mean 1mm，下蹲过渡段 mean 3mm / max 17mm，**深蹲喷涂段
  （0.45/0.35/0.25 三行）mean 6mm / max 43mm**，回位段 mean 7mm —— 在 50mm 喷涂容差内。
- 带臂负载的蹲深边界与对策：策略无臂可蹲到 0.29，**带臂前伸只到 ~0.53**（重心前移）；
  runner `--height` 用外环比例纠偏（骨盆实测反馈 K=1.8，纠偏限幅 ±0.10m）后压回 0.39，
  全程跟踪 max 4.3cm（未纠偏 13.2cm）。下蹲速率限制 0.12m/s（快速下蹲策略跟不上）。
- 工作站接线：以双姿态模式点【启动机器人】时自动给 runner 加 `--height`；
  以站姿模式启动后执行双姿态动作会明确警告。

## V2.1d 执行层任务空间伺服 —— 已完成（2026-10-10）

**现象**：仿真里"下面喷到了、中间一段没喷到"。逐帧 FK 反推实际落点（headless
`--log` 重放）确诊：

- **规划/动作本身无洞**（动作逐帧落点 0.26~1.44 连续）；
- **执行层开环注入 + 底座漂移**才是根因：底座由 RL 策略控制，实测站姿带 yaw 缓慢
  漂移（中位 +22°，最大 +40°），深蹲段骨盆前倾 +18°；而腰+臂关节按"底座在原点、
  竖直"的规划假设开环注入。落点偏差 = 底座位姿差 × tan(枪倾角)：站姿行整体低
  9.6~14.3cm，蹲姿行（倾角 60°，放大 3 倍）低 31~45.5cm，墙面 **0.34~0.61m 整段
  漏喷**（0.35 行实际喷到 -0.10m 地面上）。

**修复**（`exec/arm_task_servo.py` + `groot_spray_runner.py`）：

- **任务空间伺服**（50Hz，与策略同拍）：按实测底座位姿（root xyz + 四元数）算
  [腕心位置; 枪轴] 残差 → 解析雅可比 DLS → 修正量积分叠加到腰+臂注入目标，
  限位内裁剪。解析链与 03 的 CHAIN 逐字一致（对拍 MuJoCo FK 偏差 5.6mm 常值，
  伺服内部目标/实测同链自消）。
- **关节权限是实测教训**：腰 yaw 完全禁用——伺服用它追 y 向误差时上身旋转反作用
  会把骨盆带偏形成正反馈（实测机器人来回甩到 ±114°）；腰 roll/pitch 0.3 轻权限，
  主力 = 右臂 7 关节。修正量限幅 ±0.35 rad。
- **双环解耦结构（v6 定稿，2026-10-10 手部抖动复盘）**：
  - v3 初版用**实测关节**做 50Hz 积分反馈，与关节 PD 跟踪延迟耦合出 **~6Hz 极限环**
    ——仿真里手不停上下抖（腕 z 方向翻转率 20.3% vs 无伺服基线 3.7%，帧间位移
    p95 从 1.7mm 涨到 16.6mm）。
  - v4 改**投影命令**（动作帧+补偿，模型前馈性质）→ 抖动消除（显著翻转 0.1%），
    但不补偿 PD 重力下垂，每行均值漂到 -2.5~-7.9cm。
  - v5 慢速实测微调环初版把 `dq_slow` 也放进快环残差——**两个积分器作用在同一个
    命令上互相抵消**，反而更差（-6.5~-16.5cm）。
  - **v6 定稿**：快环只看 `motion+dq`（吃底座漂移），慢环 `dq_slow`（0.5s 一次、
    低增益 0.12、限幅 ±0.15rad）只收回 PD 下垂、**只叠加进最终注入命令**——
    实测：显著翻转 0.0%，每行落点 -3.2~+1.7cm，带内总均值 -0.4cm。
- **偏航保持（loco_cmd[2] 速率通道）实测反向失控弃用**（默认关，`--yaw-hold`
  仅实验保留）；朝向锁定归 V2.2 对墙对齐模块（官方 delta_heading 语义）。
- **落点误差进运行摘要**：runner 运行末自动统计 实际-规划 落点高度
  mean/p95/max 写入 robot_status.json，页面机器人栏直接显示（>8cm 标 ⚠）；
  页面启动 runner 自动带 `--log output/exec_last.npz`（每次执行留痕，诊断不再
  需要专门重放）。
- 摔倒阈值动作感知：深蹲动作（骨盆参考最低 0.359）下固定 0.35 只剩 9mm 余量，
  改为 `min(0.35, 动作骨盆最低-0.08)`。

**验证**（同动作 headless 重放，逐帧 FK 反推每行落点均值）：
修复前 [-45.5, -39.5, -33.2, -31.0, -13.7, -9.6, -12.9, -12.7, -13.0, -13.2,
-13.7, -14.3] cm → 修复后 **[-4.5, -0.1, 0.3, -1.1, -2.4, -2.2, -5.8, -2.0,
-1.7, 0.9, -1.4, -0.2] cm**，全部落在 ±10cm 行距/喷幅覆盖界内，0.34~0.61 空洞
消失（对比图 `runs/run_20261010_172247/fig_impact_fix_compare.png`）。剩余
p95 抖动来自底座 yaw 的秒级游走（策略固有，手臂伺服在追）；V2.2 对齐模块上线后
将进一步压缩。

## V2.1e NN-IK 一次性模型（运动学全域采样，配置解耦）—— 2026-10-10

**问题**：V2.1c 的训练采样带取自当时配置（蹲姿骨盆 `_clo` 跟随 `G1W_CROUCH_LO`、
站姿窄带），蹲姿地板 0.60→0.35 一改就得重训——"改配置=重训"违背"一次训练"的初衷。

**方案**（`12_train_nn_ik.py --universal`，数据带改为运动学极限）：沿用已验证的
"任务目标 + batch_ik 单支流形采集"管线（单支连续性是种子质量关键），仅把采样带
从"当前配置"换成"机器人运动学全域"：蹲姿组骨盆 0.30~0.70（0.30 = 膝几何可达
下界，在策略 height_cmd 限幅 0.28 的安全带内）、过渡组 0.50~0.76、站姿组
0.765~0.795，腰限四档不变——**换蹲姿地板/站位/腰限档都不再需要重训**。

**部署评估**（2026-10-10，n=300k/epochs=320）：当前 v2_dual 轨迹 iters=60 种子
收敛率 64.0%（随机 MC 23.8%）；压力档骨盆 0.30~0.34 得 49.2%（MC 17.5%）、
0.78~0.82 得 38.3%（MC 10.8%）——全域 2.7~4 倍于 MC。**诚实的权衡**：窄带
c35 专用模型在当前带 96.8%，全域模型用密度换覆盖（64.0%）；03 的种子是
分梯队的（tier-1 NN@180iters + tier-2 MC@700iters 兜底），收敛率与正确性不受
影响，只是平均求解时间略升。若未来追求两者兼得，方向 = 小型条件生成流。

**弃用记录一——构型空间采样（IKFlow 式）**：按关节限位均匀采样 q + FK 直接出
标签实测 iters=60 种子收敛率仅 34%（vs 单支流形 96.8%）：随机构型多支（肘上/
肘下）混在同一输入邻域，MLP 回归多支平均坍缩。这正是
[IKFlow](https://arxiv.org/abs/2111.08933)（RA-L 2022，条件归一化流学解流形）
用**生成式模型**而非回归的原因——若未来要彻底解决多支问题，方向是小型条件流
（规划阶段可离线推理），当前"单支流形种子 + DLS 精化"（DL-DLS 路线）够用。

**弃用记录二——全随机 pz×z 采样**：骨盆 U(0.30,0.80) × 腕心 U(0.10,1.38) 全随机
组合 + (z,y,x) 混排，保留率仅 9.4%（大量组合不可达 + 相邻目标 pz 跳变导致跳支
过滤砍链）。分组窄带结构才保得住单支流形的连续性，故最终方案 = 分组 + 运动学
带宽。

## V3 竖直列走线（用户定稿 2026-10-12）—— 已完成

**规范（用户原话归纳）**：喷涂线必须平行于"以机器人为一条线向喷涂面做垂面"的平面
（= 机器人-墙面法向竖直垂面）；枪臂恒在该垂面内 —— **手相对腕心只能上下动、不能
左右动**；60/70/80/90° 离散角都被认可（不是必须 90°），横向分量恒 0；绕枪轴旋转
不约束；横向移动只在列间跳转（kind=hop 非喷涂段）。

**实现**（03，`G1W_STROKE_DIR=vertical` 默认 / `horizontal` 回退）：
- 阶梯加密 0.05m，站姿底 0.70 起（不可行逐档抬）、蹲姿顶=站姿底+0.05（带重叠防
  水平漏带）；竖直列模式下解除 z_w 严格递增约束（那是水平行叠层防碰的约束，列内
  连续扫过整段高度，顶段上仰时腕心自然回落，无害）。
- 4 列 u=[0.154, 0.291, 0.429, 0.566]，列距 0.1375m（≤0.15 喷幅横向覆盖）；列内
  按高度阶梯插值取角（φ 线性、横向恒 0）；列间 hop + 带间回零位过渡（站/蹲阶梯
  smoothstep 混合，修掉旧硬切换的 zw/φ 阶跃；另修 hop 高度误用列终点高度的 bug
  —— 曾致 30.6 rad/s 帧速峰，修后 3.75）。
- 验收：列 u 极差=0、|axis_y|=0、喷涂角 [60.8, 90.0]° 全过、IK 288/288、碰撞 0、
  check_v2_dual 全过（新增 V3 两项）；仿真执行不摔、落点均值 +4.4cm。

**真机蹲姿修复（同日）**：运行记录显示 daemon 高度指令全程在发（planner 收到
target_height 最低 0.280）但 `mode: IDLE` —— SONIC planner 只在蹲姿系模式消费
target_height，IDLE 下机器人不蹲。daemon 改为**带滞回的模式切换**（h<0.68 切

### V3 稳定性根因与修复（2026-10-12 下午，用户实测"平行度/完成度/稳定性都很差"）

**诊断链**：执行留痕显示底座 yaw 漂到 +130~165°（机器人转过去）→ 下带没喷成、
伺服饱和、线不平行。逐层排查：

1. yaw 保持符号实验：+0.04 指令 → Δyaw +4.1°/6s，**符号正确、策略响应干净**
   （v2 时代的失控是"yaw 保持 + 当时未禁腰 yaw 的伺服"双重作用，v6 伺服后安全）。
2. **真凶**：动作的腰 yaw 用满 URDF ±150° 限位且持续爬升（0→150°）——躯干拧转
   把底座拖转。IK 冗余解无偏置时自由漂移，宽带竖直列比水平行暴露得更狠
   （健康窄带版腰 yaw 只有 ±36°，纯属运气）。
3. 修复：03/05 腰 yaw 规划级硬限位 ±45°（G1W_WAIST_YAW_MAX，网格按 ±60° 档建、
   35° 会砍掉远端角点的可达性，45° 恰好 IK 288/288）+ yaw 保持默认重开。

**弃用记录——左臂镜像联动**：意图抵消右臂横甩的反作用扭矩，但 G1 左右臂关节
符号约定未推导正确（猜的 [+,−,−,+,−,+,−]），实测直接摔倒；已默认关闭
（G1W_MIRROR_LEFT=0），要做需先按 URDF 逐关节验证镜像映射。gait 控制器路线也
不可用（本克隆无 gait 配置/策略资产，obs 95 维对不上）。

**修复后终验（headless 全程）**：yaw [-3.9,+33.5]° 中位 +8.1（不再转圈）；腕心
跟踪 mean 2.1cm / p95 4.3cm（竖直线由跟踪保证平行）；覆盖 0.25~1.45 无空箱；
不摔；落点均值 +4.2cm。视觉验收（回放 12 时刻 + 走线图）双 PASS：全程面向墙、
t≈53-120s 深蹲稳定、臂恒指墙。
